## Agent Patches
The `agent-patches/` directory contains generated patch files from different coding agents for Defects4J bugs:
- **`claude_patches/`** - Patches generated by Claude Code
- **`codex_patches/`** - Patches generated by Codex
- **`gemini_patches/`** - Patches generated by Gemini
- **`qwen_patches/`** - Patches generated by Qwen Code

Each subdirectory contains diff files named by bug ID (e.g., `Chart_14.diff`, `Closure_10.diff`) representing the agent's attempted repair for that specific bug.
