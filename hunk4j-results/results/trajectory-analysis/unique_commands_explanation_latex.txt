Coding agents differ in how they interact with the development environment. Each agent has access to both native framework tools and shell command execution capabilities. Native tools are agent-specific functions provided by the framework, such as \texttt{read\_file}, \texttt{edit}, and \texttt{glob}. Shell commands are standard Unix utilities and domain-specific tools executed through bash, including \texttt{sed}, \texttt{grep}, \texttt{defects4j test}, and \texttt{git diff}.

Table~\ref{tab:unique_commands_per_agent} presents the diversity of unique commands employed by each agent across all repair attempts. The total unique count represents the distinct commands used at least once during the evaluation. Native tools and bash commands are counted separately to characterize each agent's interaction paradigm.

OpenAI Codex relies exclusively on bash commands (96 unique commands, 100\%), executing all operations through shell interfaces. This design reflects a terminal-centric interaction model where every action—file reading, editing, searching, building, and testing—is performed via command-line utilities. Qwen Code and Claude Code exhibit similar patterns, using primarily bash commands (89.0\% and 90.9\% respectively) with minimal native tool support (10--11 unique native tools). In contrast, Gemini CLI demonstrates more balanced usage, with 28.9\% of unique commands being native tools (11 tools) and 71.1\% bash commands (27 commands).

The variation in command diversity reflects different design philosophies. Codex's extensive command repertoire (96 unique) indicates broad utilization of shell utilities and frequent exploration of different tools. Qwen employs 91 unique commands, suggesting similarly diverse tool usage. Claude uses 66 unique commands, indicating a more focused toolkit. Gemini's 38 unique commands represent the most constrained command set, potentially reflecting either a more streamlined workflow or more limited exploration during repair attempts.

This diversity in tool usage has implications for repair behavior. Agents with larger command repertoires may explore more varied strategies, while agents with focused toolsets may rely on consistent, repeatable workflows. The balance between native tools and bash commands further shapes interaction patterns: bash-heavy agents must construct complex command pipelines and parse unstructured text output, while agents leveraging native tools benefit from structured data interfaces and tighter framework integration.
